# Contributing

Thanks for your interest in contributing to the Omutwar Registration Service.

This project follows a clean, modular architecture. Please keep changes focused, consistent, and aligned with the existing structure.

## Guidelines

- Keep PRs small and purposeful  
- Follow the existing package layout  
- Write clear commit messages  
- Avoid introducing unnecessary dependencies  
- Do not commit secrets or environment files
