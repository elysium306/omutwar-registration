# Roadmap

This document outlines the planned evolution of the Omutwar Registration Service.

## Phase 1 — Identity Foundation (Current)
- User creation and lifecycle
- Invitation-based onboarding
- Secure password handling
- Clean modular architecture

## Phase 2 — Role & Access Model
- Role entity and user-role mapping
- Partner and vendor domain models
- Role-based authentication flows

## Phase 3 — Multi-Tenant Expansion
- Partner onboarding
- Vendor onboarding
- Tenant-aware data access

## Phase 4 — Platform Integration
- API gateway integration
- Frontend portal integration
- Metrics and audit logging

## Phase 5 — Hardening & Deployment
- CI/CD pipeline
- Production configuration
- Security hardening
